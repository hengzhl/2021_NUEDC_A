# 2021 年电赛 A 题：信号失真度测量装置

本人以 2021 年全国大学生电子设计竞赛 A 题为练习，基于 **TI MSPM0G3519** 完成信号采集、谐波分析与串口屏显示的关键功能。题目要求见 [原题附件](信号失真度测量装置（A题）.pdf)。

## 主要功能

- **信号采集**：定时器触发片内 12 位 ADC，DMA 搬运，采样率 1.25 MSa/s，每批 1024 点。
- **信号分析**：去直流、加 Hann 窗、1024 点 FFT，估计基频、谐波幅值及 THD。
- **波形显示**：粗略识别正弦波、三角波和方波，估算峰峰值，向串口屏发送数值和 120 点波形。
- **启停控制**：串口接收原始字节 `0x01` 启动、`0x00` 停止。

目前已完成 ADC 采集到串口屏显示的流程，**蓝牙及手机显示尚未调通**。

## 代码结构

工程位于 `TI21_A_MSPM0G3519/`：

| 文件 | 作用 |
| --- | --- |
| `empty.c` | 主循环、采集控制、中断和数据显示 |
| `empty.syscfg` | 时钟、ADC、DMA、定时器与串口配置 |
| `usercode/thd_m0.c` | FFT、频率估计、谐波提取和 THD 计算 |
| `usercode/adc_processor.c` | 波形平滑、触发点查找与显示插值 |
| `usercode/zhl_io.c` | 串口格式化输出 |

## 使用方法

1. 使用 **CCS + MSPM0 SDK + SysConfig** 导入工程，按本机环境调整工具版本和依赖路径，确保 CMSIS-DSP 可用。
2. 打开 `empty.syscfg`，核对时钟和引脚配置，重新生成并编译，使用 XDS110 下载程序。当前配置使用 40 MHz 外部晶振。
3. 调理后的模拟信号接 **PB24（ADC0 通道 5）**；串口屏 RX 接 **PC0**、TX 接 **PC1**，双方共地，串口设为 **9600、8N1**。输入信号需处于 ADC 允许范围内。
4. 串口屏发送启停字节；屏幕控件需与 `empty.c` 中的名称匹配。仓库未包含串口屏界面和模拟前端设计文件。

## 说明

当前代码统计 **2～9 次谐波**计算 THD，原题仅统计 **2～5 次**；程序中的 `0.05` 表示 `5%`。固定采样参数对 1 kHz 等低频信号仍需调整，项目未提供完整题目指标的测试记录。
